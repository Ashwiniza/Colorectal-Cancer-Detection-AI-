# Colorectal Cancer Detection Using AI

## Project Overview

This research project explores the application of machine learning and deep learning techniques for colorectal cancer detection using medical images obtained from colonoscopy examinations.

The project investigates image-based feature extraction and classification approaches to support computer-aided analysis of colorectal cancer.

## Research Objectives

- Explore and preprocess colorectal cancer image data.
- Perform exploratory data analysis (EDA).
- Investigate deep learning-based image feature extraction.
- Develop and evaluate machine learning classification models.
- Explore the potential of AI-assisted colorectal cancer detection.

## Project Structure

| Notebook | Description |
|---|---|
| `01_Exploratory_Data_Analysis.ipynb` | Exploratory data analysis and dataset familiarisation |
| `02_Case_Level_Model_Training.ipynb` | Case-level data preparation and model training |
| `03_CNN_AdaBoost_XGBoost.ipynb` | Experimental CNN and ensemble learning approaches |

## Research and Publication Status

A manuscript based on this research has been submitted to *Computer Methods and Programs in Biomedicine* (Elsevier) and is awaiting an editorial decision.

**Publication status:** Submitted; not yet published.

## Dataset and Reproducibility

The original colorectal cancer medical image dataset is available to the researcher and is stored on an external hard drive due to its large storage requirements.

The dataset is not uploaded to this public repository. This repository contains the research notebooks and implementation code.

Reproducing the complete experiments requires access to the original dataset and the corresponding computational environment. Access to the dataset may be subject to applicable permissions and restrictions.
